What, why, and how

Example: sqrt()

sqrt(64)
#| [1] 8
64 |> sqrt()
#| [1] 8
  • traditional use of functions: function(argument)
  • piping: argument |> function()

Example: sqrt()

sqrt(64)
#| [1] 8
64 |> sqrt()
#| [1] 8
  • another way to think about this is that piping reverses the phrasing
  • in the traditional use of functions, we write the verb and then the noun
  • with piping, we write the noun and then the verb

Why would I do this?

  • I’ll share illustrative examples, highlighting 3 reasons why piping can be useful
  • I’ll explain the details later
  • for now, focus on what’s different in the piping examples

Setup for some coming examples

  • load some packages:
library(ggplot2) # for ggplot()
library(baseverse) # for base_when()
  • import the NHANES data:
nhanes <- read.csv('nhanes_l.csv')

Example: a ggplot scatterplot

ggplot(data = nhanes, mapping = aes(x = bpxodi1, y = bpxosy1)) +
  geom_point() +
  labs(x = 'Diastolic (mmHg)', y = 'Systolic (mmHg)')

Example: a ggplot scatterplot

  • with piping, I could instead write this:
nhanes |> ggplot(aes(x = bmxht, y = bmxwt)) +
  geom_point() +
  labs(x = 'Diastolic (mmHg)', y = 'Systolic (mmHg)')
  • notice that this allows me to omit the data argument in ggplot()

Example: cholesterol

  • from A Slower Introduction to R:
nhanes$cholesterol <- base_when(
  'Desirable' = (nhanes$lbxtc < 200),
  'Borderline high' = (nhanes$lbxtc >= 200) & (nhanes$lbxtc < 240),
  'High' = (nhanes$lbxtc >= 240)
)

Example: cholesterol

  • with piping, I could instead write this:
nhanes <- nhanes |>
  transform(cholesterol = base_when(
    'Desirable' = (lbxtc < 200),
    'Borderline high' = (lbxtc >= 200) & (lbxtc < 240),
    'High' = (lbxtc >= 240)
  ))
  • notice that this allows me to omit dollar-sign notation

Example: a data snippet

  • suppose that I want to glance at the data for the subset of people with a history of smoking:
head(subset(
  nhanes,
  smoking == 'History of smoking',
  select = c(hypertension, smoking)
))
  • this is difficult to read because it nests a long use of subset() within head()

Example: a data snippet

  • with piping, I could instead write this:
nhanes |>
  subset(smoking == 'History of smoking',
         select = c(hypertension, smoking)) |>
  subset() |>
  head()
  • notice that this allows me to avoid nested functions

Example: a data snippet

  • I can split the use of subset() into two uses to make it even easier to read:
nhanes |>
  subset(smoking == 'History of smoking') |>
  subset(select = c('hypertension', 'smoking')) |>
  head()

In summary

  • you can use piping to avoid the data argument
  • you can use piping to avoid dollar-sign notation
  • you can use piping to avoid nested functions

Haven’t I seen something like this somewhere else?

  • possibly, yes!
  • piping is a core feature of the tidyverse, in packages like dplyr
  • originally, the tidyverse used the character sequence %>%

Haven’t I seen something like this somewhere else?

  • in 2021, base R added support for piping, using the character sequence |>
  • this sequence is known as the native pipe because it is part of base R

With the introduction of the native pipe, many tidyverse users are transitioning to |>, but it’s still possible to use %>% with tidyverse packages.

So how do I do this?

  • in general, the pattern is: argument |> function()
  • more precisely, because many functions have multiple possible arguments, the pattern is: first argument of the function |> function()

mean()

  • without piping:
mean(nhanes$bpxodi1, na.rm = TRUE)
#| [1] 74.97469
  • with piping:
nhanes$bpxodi1 |> mean(na.rm = TRUE)
#| [1] 74.97469
  • notice that I’ve kept the na.rm argument in mean()
  • the phrasing is roughly: “with diastolic blood pressure, take the mean, and ignore missing values when you do so”

head()

  • without piping:
head(nhanes, n = 3)
  • this shows the first 3 rows of nhanes
  • with piping:
nhanes |> head(n = 3)
  • notice that I’ve kept the n argument in head()

head() and dim()

  • without piping:
dim(head(nhanes, n = 3))
  • with piping:
nhanes |> 
  head(n = 3) |>
  dim()
  • this forms a longer pipeline
  • each pipe adds to the result up to that point

Pipelines

  • a cooking analogy:
cookie_dough |>
  chill(hours=24) |>
  scoop(ounces=1.75, quantity = 20) |>
  roll() |>
  bake(minutes=14)
  • each pipe adds to the result up to that point
  • for example, the third line calls for scooping the chilled dough

Defining variables

Object assignment

  • to define a new variable:
nhanes$new_variable<-1

transform()

  • equivalently, use the transform() function:
minidata <- transform(minidata, new_variable = 1)
  • here, transform() returns a version of minidata with a new variable added called new_variable
  • = 1 defines the values of new_variable
  • what would happen if I didn’t include include minidata <-?

transform()

minidata <- transform(minidata, new_variable = 1)
  • in general, the second argument is: variable name = definition of new variable

transform() with piping

  • with piping:
minidata <- minidata |>
  transform(new_variable = 1)
  • minidata now looks like this:
minidata |> head()
#|   bmxht new_variable
#| 1 179.5            1
#| 2 174.2            1
#| 3 152.9            1
#| 4    NA            1
#| 5    NA            1
#| 6 173.3            1

transform() with piping

  • to convert bmxht to inches:
minidata <- minidata |>

Defining missing values

  • the replace() strategy for defining missing values from Session 6 of A Slower Introduction to R can be combined with transform() and piping:
nhanes <- nhanes |> 
  transform(
    ltpa_vigorous = replace(pad820, pad820 == 7777 | pad820 == 9999, NA)
  )

Defining missing values

  • another option, mentioned in Homework 6 from A Slower Introduction to R, is to use is.na() and object assignment
  • that strategy can be combined with within() and piping:
nhanes <- nhanes |> within({
  ltpa_vigorous <- pad820
  is.na(ltpa_vigorous) <- pad820 == 7777 | pad820 == 9999
})

Defining categorical variables

  • all of the strategies from Session 7 of A Slower Introduction to R can be combined with transform() and piping

Labeling categorical variables

  • using factor():
nhanes <- nhanes |>
  transform(country = factor(
    dmdborn4,
    levels = c(1, 2),
    labels = c('USA', 'Other')
  ))
  • or, using base_match() from my baseverse package:
nhanes <- nhanes |>
  transform(country = base_match(dmdborn4, 'USA' = 1, 'Other' = 2))

Labeling categorical variables

  • country looks like this:
nhanes$country |> table(useNA='always')
#| 
#|   USA Other  <NA> 
#|  6519  1617    17
  • whereas dmdborn4 looks like this:
nhanes$dmdborn4 |> table(useNA='always')
#| 
#|    1    2 <NA> 
#| 6519 1617   17

Categorizing continuous variables

  • using cut():
nhanes <- nhanes |>
  transform(cholesterol = cut(
    lbxtc,
    breaks = c(0, 200, 240, Inf),
    labels = c('Desirable', 'Borderline high', 'High'),
    right = FALSE
  ))

Categorizing continuous variables

  • or, using base_when() from my baseverse package:
nhanes <- nhanes |>
  transform(cholesterol = base_when(
    'Desirable' = (lbxtc < 200),
    'Borderline high' = (lbxtc >= 200) & (lbxtc < 240),
    'High' = (lbxtc >= 240)
  ))
